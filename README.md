# Galen Marten Music

Official website for Galen Marten — one-man band out of Ohio.
Static HTML/CSS/JS, no build step. Deploys from GitHub to Netlify (`netlify.toml` → publish `site/`).

- **Update shows:** edit `site/data/shows.json` (past shows hide automatically). Show art lives in `site/assets/img/shows/`.
- **Forms:** contact + newsletter run on Netlify Forms (submissions in the Netlify dashboard).
- **Merch:** printed and shipped by Printful; see `CLAUDE.md` for how the buy links are wired during the Wix transition.

Maintained with Claude Code — see `CLAUDE.md` for the full playbook.
